# Мониторинг цен ПРОМЕТ

> **Статус публикации:** в репозиторий загружены исходный код и конфигурация. Файлы `data/observations.json` и `public/index.html` пока не опубликованы: они содержат снимок цен, наличия, акций и счётчиков продаж и ожидают подтверждения владельца на публичное размещение. Перечень ниже описывает полный исходный пакет. Для сборки и Docker-запуска требуется добавить исходный `data/observations.json`; готовую страницу затем создаёт `python scripts/build.py`.

Самостоятельная версия дашборда для коммерческого директора: 13 моделей, предложения ПРОМЕТ и конкурентов, фильтры дилеров и производителей, графики, акции, сводка Word и экспорт Excel. Для работы не нужны Codex или Sites.

## Что готово

- Полный интерфейс и исходный JavaScript/CSS в `src/dashboard.html`.
- Данные открытых карточек дилеров в `data/observations.json`.
- Готовая страница `public/index.html`, включая защищённый iframe, CSP и разрешение скачивания файлов.
- Локальное сохранение фильтров в браузере, без аккаунта.
- Сборка на Python без сторонних библиотек; конфигурация Docker и nginx.

## Запуск через Docker

```sh
docker compose up -d --build
```

Откройте `http://localhost:8080` или `http://АДРЕС_СЕРВЕРА:8080`. Для домена и HTTPS подключите ваш reverse proxy. Изменение порта выполняется в `compose.yaml`.

## Запуск без Docker

Нужен Python 3.10 или новее только для сборки и локального просмотра:

```sh
python scripts/build.py
python -m http.server 8080 --directory public
```

На рабочем сервере достаточно скопировать содержимое `public` в каталог сайта nginx/Apache. Python HTTP server предназначен для локальной проверки. Серверная база данных не нужна. Браузеру требуется доступ к CDN, перечисленным в CSP исходной страницы.

## Обновление данных

1. Отредактируйте `data/observations.json`.
2. Сохраните предыдущие записи в `history.own` и `history.analogs`, прежде чем заменить текущие `own` и `analogs`.
3. Выполните `python scripts/build.py` и замените `public/index.html` на сервере либо повторите `docker compose up -d --build`.

Основные поля: `sku` — артикул ПРОМЕТ; `skus` — массив подходящих артикулов у аналога; `model`, `maker`, `site`, `url`, `price`, `checkedAt` (ISO 8601 с часовым поясом), `statusObserved`, `conditionalPrice`, `conditionalType`, `promo`, `unavailablePrice`. Неизвестная цена обозначается `null`, а не нулём. `soldUnits` — накопленный счётчик сайта Железная мебель, не недельные продажи.

`selected` задаёт модели, `pairs` — соответствия и отличия аналогов, `coverage` — покрытие проверки. Одно предложение хранится один раз с несколькими `skus`; не дублируйте его для каждого артикула.

## Границы текущего прототипа

Это дашборд с сохранённым снимком, а не работающий автономный парсер сайтов. В комплекте нет планировщика, API дилеров, обхода CAPTCHA или сервиса автоматического сбора. Исходные наблюдения относятся к неделе 44 2026 года. Не считайте их текущими ценами без повторной проверки.

В `tools/parse_captures.py` сохранён вспомогательный разбор уже полученного текста карточек. Он не загружает сайты и не подтверждает цену автоматически:

```sh
python tools/parse_captures.py input.json output.json
```

Вход — массив объектов с `site` и `text`; выход — найденные строки цен, наличия и размеров для последующей проверки.

Графики на экране поддерживают историю по неделям. Экспорт Excel сейчас показывает текущий снимок и использует подпись «Неделя 44»; график в Excel также относится к текущему снимку. При обновлении периода замените подписи в `src/dashboard.html` или доработайте их автоматический расчёт. Word формируется по выбранным наблюдениям; порог критичного изменения задаётся в интерфейсе.

## Безопасность и состав

В пакет не включены токены, настройки Sites, история Git, исходный внутренний отчёт об отгрузке и личные файлы. Не отключайте CSP и sandbox для исправления отдельных функций; для скачивания предусмотрено только `allow-downloads` вместе с `allow-scripts`.
