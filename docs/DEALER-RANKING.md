# Рейтинг «Демпинг»

Доступен из журнала событий. Используется текущий город и весь накопленный период истории собственных моделей ПРОМЕТ (`history.own` и `own`). Знаменатель — число уникальных SKU из `selected`, то есть моделей реестра мониторинга, а не количество предложений или отфильтрованных строк конкурентов. Фильтры страницы конкурентов не меняют рейтинг.

Для каждой пары SKU/дилер выбирается самая низкая подтверждённая положительная обычная или акционная цена товара «В наличии». Условная цена и цена отсутствующего товара не подставляются. Записи с ошибками цены, сбора или наличия, некорректной или будущей датой исключены. Далее сравниваются минимумы дилеров для каждого SKU; нужно не менее двух дилеров с допустимыми наблюдениями. При равном минимуме каждый дилер получает одну модель. Повторы и несколько минимумов одного дилера не увеличивают его счёт.

Доля = число моделей с общим историческим минимумом у дилера / все модели реестра × 100%. Недостаточно покрытые модели остаются в знаменателе. Отдельно показаны охват цен и число сопоставимых моделей. Равные результаты делят место; сумма долей может превышать 100%. Раскрываемый список показывает модели, цены, даты и разделённые минимумы.

Это историческое ценовое лидерство: наблюдения разных дилеров могут относиться к разным датам. Показатель не означает сегодняшнюю самую низкую цену, частоту лидерства или продажи ниже себестоимости. Данные не обновляются открытием рейтинга. Переключение города пересчитывает рейтинг только по его наблюдениям.
