# Обновление: Москва и Санкт-Петербург

Включены реальные наблюдения от 02.11.2026: по 170 карточек на каждый город, 13 SKU, четыре дилера. Фильтр города переключает сохранённые сведения. Сравнение только у одного дилера в одном городе. История Москвы сохранена; история СПб начинается с этого снимка. Условные цены не смешиваются с публичными. Кнопка обновления города отключена: серверный запуск из интерфейса не подключён.

На установленном сервере:

```sh
promet-parser-update --code-only
```

Этот вариант обновляет программу и страницу без запуска нового сетевого сбора. Существующий серверный сборщик сохранён, но сбор по двум городам к нему пока не подключён. Объединение обновления с рабочими наблюдениями сохраняет новые записи сервера и отдельный массив СПб.

Для статического размещения без установленной команды, в каталоге репозитория:

```sh
git pull --ff-only
python3 scripts/build.py
sudo install -m 644 public/index.html /var/www/pars.promet.pw/public/index.html
```

Порт 8080 не требуется. Конфигурация Nginx, HTTPS и пароли этим пакетом не меняются. Docker здесь не проверялся.

Наличие ЖМ относится к центральным складам; счётчик покупок не подтверждён как городской. Цены safe.ru для СПб не собирались: «Нет данных» в синей карточке означает отсутствие регионального наблюдения, а не нулевую цену. Архивные отчёты доступны только для Москвы.
