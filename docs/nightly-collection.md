# Ежедневный ночной сбор

Правило владельца от 10.11.2026: каждый день, начало в 00:00 Europe/Moscow. Охват — все зарегистрированные модели (включая AFC-04/05), площадки, Москва и Санкт-Петербург, справочные цены производителя. Это время начала, а не гарантия завершения: обязательные паузы источников сохраняются.

Автоматическое продолжение настроено в текущем чате Codex. Для локального сбора компьютер, приложение и сеть должны быть доступны. Если ночной запуск пропущен, не начинать полный сбор днём без отдельного указания владельца. Уже начатый медленный прогон можно завершить без сокращения пауз.

Перед запуском проверить активные процессы, состояние и последние отчёты. Не создавать второй сборщик, если первый ещё работает. Использовать отдельную папку состояния ночного прогона, продолжать незавершённый, не повторять подтверждённые проверки в рамках одного прогона. Не запускать старые одноразовые скрипты быстрого сбора с датами 5/9 ноября.

## Защита сайтов и качество

- CAPTCHA и «Я не робот» проходит только пользователь. Не обходить и не решать автоматически. Сохранить очередь площадки, оставить проверку пользователю, продолжить доступные площадки. Не повторять уже ожидающий вопрос.
- Соблюдать robots.txt, crawl-delay, Retry-After и ограниченные повторы. Не сокращать пятиминутные паузы Альфа-Гарант ради расписания.
- Проверять модель, комплектацию и город. Секцию не принимать за полный шкаф. Использовать проверенные региональные адаптеры; отсутствие адаптера не заменять предположением о городе.
- Не подставлять старую цену с новой датой. При ошибке сохранить прошлое наблюдение, исходную дату и причину пропуска. Условные цены, акции и наличие — по существующим правилам.
- Перед изменениями создать резервную копию. Сохранить историю, объединить только подтверждённые наблюдения, проверить уникальность и охват. Сформировать HTML и отчёт с исключениями в outputs. Сохранение проекта в GitHub — по AGENTS.md; развёртывание сервера отдельно.

Сообщать итог прогона, существенный сбой или необходимое действие пользователя. Постоянное расписание после одного прогона не удалять.

## Сервер

Шаблон deploy/promet-parser-refresh.timer также переведён на 00:00 МСК. Persistent=false предотвращает запуск пропущенного таймера при дневном включении. Это изменение файла в репозитории, не подтверждение изменения установленного таймера на pars.promet.pw. Не включать одновременно серверный и локальный полный сбор без координации. При переносе расписания на сервер сначала проверить региональный охват сборщика и отключить дублирующий локальный запуск.
