# Пакет обновления — 2 ноября 2026

Пакет содержит последний сохранённый интерфейс и реальные наблюдения 28–30 октября 2026: 13 моделей, 48 предложений ПРОМЕТ, 122 предложения конкурентов и 13 справочных цен safe.ru. Дата пакета не означает повторную проверку цен. Цены safe.ru отделены от дилерских предложений.

## Обновление установленной программы

Для установки, выполненной через deploy/install.sh, сначала сохраните резервную копию страницы и серверных данных:

```sh
backup_dir="/var/backups/promet-parser/$(date +%Y%m%d-%H%M%S)"
sudo mkdir -p "$backup_dir"
sudo cp -a /var/www/pars.promet.pw/public/index.html "$backup_dir/index.html"
sudo cp -a /var/lib/promet-parser/observations.json "$backup_dir/observations.json"
sudo promet-parser-update --code-only
```

Команда получает GitHub main и пересобирает страницу с серверными наблюдениями. Более свежие серверные цены сохраняются; новые справочные цены и соответствия из пакета добавляются. Расписание, пароли, HTTPS и конфигурация Nginx не изменяются. Сбор цен этой командой не запускается. При локальных изменениях Git может остановить обновление — не применяйте reset --hard, сначала сохраните и согласуйте изменения.

После обновления откройте https://pars.promet.pw/ с принудительным обновлением страницы. Проверьте каталог: рядом с моделью должна быть цена safe.ru; затем выбор производителя и сравнение с ПРОМЕТ. Для просмотра последнего журнала уже настроенного сборщика:

```sh
sudo journalctl -u promet-parser-refresh.service -n 50 --no-pager
```

## Если используется только статический Nginx

В каталоге репозитория выполните git pull --ff-only, затем сборку. Если есть отдельный файл более свежих наблюдений, обязательно используйте --data с его путём; не заменяйте его снимком из пакета.

```sh
git pull --ff-only
python3 scripts/build.py
sudo install -m 644 public/index.html /var/www/pars.promet.pw/public/index.html
```

Перезапуск Nginx для замены HTML не требуется. Порт 8080 не используется. Существующую защиту доступа и сертификаты сохраняйте.
